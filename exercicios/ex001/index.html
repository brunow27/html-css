HYPERTEXT MARKUP LANGUAGE (HTML) é uma linguagem de marcação utilizada na construção de páginas na web. Ela permite estruturar o conteúdo, como textos, imagens, links e outros elementos, de forma organizada e semântica. Com o HTML, é possível criar sites interativos e visualmente atraentes, proporcionando uma experiência agradável para os usuários.
